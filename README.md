# STALKER_TAP_Automation
## Інструкція: Як запустити автоматизацію для STALKER TAP у Telegram Desktop

Цей документ містить покрокову інструкцію з налаштування та запуску JavaScript-скрипта для автоматизації взаємодії (тапу) з елементами гри через вбудовані інструменти розробника (DevTools).

### 1. Підготовка середовища: Увімкнення WebView Inspecting

Для того, щоб отримати доступ до DOM-дерева гри, необхідно активувати режим розробника в клієнті Telegram.

1. Відкрийте **Налаштування** (Settings) у Telegram Desktop.
2. Перейдіть до розділу **Просунуті налаштування** (Advanced).
3. Прокрутіть сторінку до самого низу та натисніть на **Експериментальні налаштування** (Experimental settings).
4. Знайдіть і активуйте перемикач **Enable webview inspecting**.
5. Повністю перезапустіть Telegram (закрийте програму повністю, вийшовши з неї в системному треї, і відкрийте знову).

*Примітка: Якщо розділ "Експериментальні налаштування" відсутній, у "Просунутих налаштуваннях" швидко клікніть 5-6 разів по номеру версії Telegram внизу вікна. У прихованому Debug-меню, що з'явиться, виберіть **Enable webview inspecting**.*

### 2. Доступ до консолі та налаштування безпеки

1. Запустіть міні-додаток STALKER TAP.
2. Натисніть **F12** або комбінацію **Ctrl + Shift + I** на клавіатурі для виклику вікна DevTools. 
3. Перейдіть на вкладку **Console**.
4. З міркувань безпеки браузерний рушій може блокувати виконання стороннього коду. Щоб зняти це обмеження, введіть у консолі команду `allow pasting` і натисніть **Enter**.
